# User guides

Start with [installation and setup](getting-started.md), then choose the workflow you need:

| Task | Guide |
| --- | --- |
| Build a pedal signal path, switch modes, or use footswitch/browser/LVGL control | [Live effect](live-effect.md) |
| Install effects from the LV2 catalog and load them into the pedal library | [Add LV2 plugins](lv2-plugins.md) |
| Prepare recordings, train a pitch classifier, predict WAV files, or benchmark it | [Pitch classifier](pitch-classifier.md) |
| Trigger a fixed MIDI note from input volume | [Audio-to-MIDI](audio-to-midi.md) |

The live effect, offline classifier, and MIDI trigger run independently. Training a classifier does not change the sound of the live effect.
